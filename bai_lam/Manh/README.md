# Phần dữ liệu của Mạnh

Các bài đã được chuyển đổi từ file `.md` gốc sang cấu trúc thư mục từng bài (`Bxxx_ten_bai/`) theo chuẩn `OUTPUT_CONTRACT.md` và `guidelines.pdf` (giống định dạng trong `bai_lam/Tuan/`). Toàn bộ file `.md` gốc vẫn được giữ nguyên để truy vết.

- **`CPO_03/` (*Ngô Thì Nhậm toàn tập 1*, `source_4.pdf`):** 15 bài văn xuôi (`B001`–`B015`), tổng **448 cặp** dóng hàng 2 cột (`Hán`, `Việt`). Theo dõi chi tiết tại `CPO_03/TODO.tsv`.
- **`CPO_04/` (*Thơ văn Phan Huy Ích 2*, `source_5.pdf`):** 9 bài thơ đủ 4 bản (`B001`–`B009`), tổng **96 hàng** dóng hàng 4 cột (`Hán`, `Dịch âm`, `Dịch nghĩa`, `Dịch thơ`). Còn 66 bài thơ thiếu bản dịch thơ giữ ở trạng thái `Cần hỏi` trong `CPO_04/TODO.tsv`.

Trạng thái tất cả các gói bài hiện là **đối chiếu sơ bộ**; cần kiểm chéo với ảnh PDF nguồn (đặc biệt các chỗ chữ Hán khuyết do OCR trong `CPO_03`) trước khi đổi sang hoàn thành.
